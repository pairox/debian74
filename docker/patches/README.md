# PHP 7.4: происхождение патчей

Проверено 20.11.2026 (Europe/Minsk). Идентификатор набора:
`sury-7.4.33-37-20261119`. Это отобранные патчи исходников, а не установка
готовых PHP-пакетов Surý или обещание полной поддержки PHP 7.4.

Источник: [packages.sury.org](https://packages.sury.org/php/pool/main/p/php7.4/),
пакет `1:7.4.33-37+debsuryorg12.1+php+1`, архив
`php7.4_7.4.33-37+debsuryorg12.1+php+1.debian.tar.xz`.
SHA-256 архива из опубликованного индекса `bookworm/main/source/Sources.xz`:
`56360570ece3981c5842871b7f6ed1006cdb60af5e7887a6d5ed63a49d271164`.
Индекс и архив получены по HTTPS; подпись APT Release отдельно не проверялась.

`series` задаёт порядок 149 **неизменённых** патчей из этого архива;
`SHA256SUMS` фиксирует содержимое и порядок. `upstream-changelog` и
`upstream-copyright` сохраняют журнал поставщика и сведения о лицензировании.
Исходный PHP 7.4.33:
`924846abf93bc613815c55dd3f5809377813ac62a9ec4eb3778675b82a27b927`.

Взяты номера 0047–0222, кроме 0051, 0052 (документация поставщика),
0127, 0197 (DNS telemetry), 0171–0192 (адаптация тестов под Debian packaging)
и 0196 (alias для изменённого Debian enchant). Патчи 0001–0046 меняют
пакетирование/пути Debian и не нужны для установки в `/usr/local`.
Существующий одиночный октябрьский патч заменён патчем 0163 в общей серии;
он применяется после более ранних исправлений multipart.

Ноябрьские исправления находятся в 0203–0222, включая CVE-2026-129538,
129496, 129289, 129292, 129291, 128090, 126714, 115560, 15353,
129506, 128064, 127960 (все с префиксом CVE-2026-).
Точные изменения и предшествующие исправления — в `upstream-changelog`.
Включены исправления OpenSSL 3, ICU и libxml для новой базовой ОС.

Ограничения: журнал поставщика помечает старый mysqlnd backport
CVE-2025-1218 как частичный; это не полный аудит PHP и всех библиотек.
Нет оснований заявлять «все уязвимости устранены». Бинарная сборка,
регрессионные тесты upstream, сканирование и приложения локально не запускались.
Проверено только применение всей серии к чистым исходникам с `--fuzz=0`.
После успешного CI нужны тесты приложений и проверка отчёта сканера.
